# Shopping Cart Total Calculator (Console Application)

A simple **Core Java console application** that calculates the total cost of a purchased item based on its quantity and unit price. This project demonstrates user input handling, arithmetic operations, variables, and console output while simulating a basic shopping cart calculation.

---

## Features

- Accepts item name from the user
- Takes quantity and unit price as input
- Calculates the total purchase amount
- Displays a purchase summary
- Beginner-friendly console application

---

## Technologies Used

- Java
- Core Java
- Console Application
- Scanner Class
- Variables
- Data Types
- Arithmetic Operators

---

## Project Structure

- **Cart.java** – Contains the main method, user input handling, total price calculation, and purchase summary display.

---

## How It Works

1. The program prompts the user to enter the item name.
2. The user enters the quantity of the item.
3. The user enters the price per unit.
4. The program calculates the total cost by multiplying the quantity by the unit price.
5. The purchase summary and total amount are displayed on the console.

---

## Installation & Usage

Compile the program:

```bash
javac Cart.java
```

Run the program:

```bash
java Cart
```
